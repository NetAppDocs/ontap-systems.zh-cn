= 在更换 FAS9000 系统中的机箱之前，请查看相关要求
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在更换 FAS9000 系统中的机箱之前，请验证所有其他组件是否正常运行，以及更换用的机箱是否与受损机箱型号相同。此操作过程会造成中断，导致双节点集群中的完整服务中断或多节点集群中的部分中断。

系统中的所有其他组件必须正常运行；否则，您必须联系技术支持。

* 您可以将此操作步骤与系统支持的所有 ONTAP 版本结合使用。
* 此操作步骤会造成系统中断。对于双节点集群，多节点集群将发生完全服务中断和部分中断。
