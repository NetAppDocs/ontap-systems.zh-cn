= 了解如何维护您的 AFF A150 存储系统
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
维护 AFF A150 存储系统的硬件，以确保长期可靠性和最佳性能。执行定期维护任务，例如更换故障组件，以帮助防止停机和数据丢失。



[[boot-media]]
== 启动介质

启动介质用于存储系统在启动时使用的一组主启动映像文件和一组二级启动映像文件。



[[chassis]]
== 机箱

机箱是托管所有控制器组件(例如控制器/CPU单元、电源和I/O)的物理机箱



[[controller]]
== 控制器

控制器由主板，固件和软件组成。它控制驱动器并实现ONTAP功能。



[[dimm]]
== DIMM

如果存在内存不匹配或 DIMM 发生故障，则必须更换 DIMM （双列直插式内存模块）。



[[drive]]
== 驱动器

驱动器是为数据提供物理存储介质的设备。



[[nvem-battery]]
== NVEM电池

控制器附带电池，如果交流电源发生故障，则会保留缓存的数据。



[[power-supply]]
== 电源

电源可在控制器架中提供冗余电源。



[[real-time-clock-battery]]
== 实时时钟电池

实时时钟电池可在断电时保留系统日期和时间信息。
