= 将故障的 FAS2700 启动介质返回给 NetApp
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
更换 FAS2700 系统上的启动介质后，将故障部件退回 NetApp，如套件附带的 RMA 说明中所述。

有关更多信息，请参阅 https://mysupport.netapp.com/site/info/rma["部件退回和更换"]页面。FAS2700 系统仅支持手动启动介质恢复过程。不支持自动启动介质恢复。
