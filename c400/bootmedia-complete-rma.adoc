= 在手动启动恢复过程完成后，将故障的 AFF C400 启动介质退回给 NetApp
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
更换后，请按照套件附带的 RMA 说明，将故障的 AFF C400 启动介质退回至 NetApp。

按照套件随附的 RMA 说明将故障部件退回 NetApp 。 https://mysupport.netapp.com/site/info/rma["部件退回和更换"]有关详细信息、请参见页面。
