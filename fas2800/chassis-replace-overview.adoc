= 在更换 FAS2820 系统中的机箱之前，请查看相关要求
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
要更换 FAS2820 系统中的机箱，请将电源、硬盘驱动器和控制器模块从受损机箱移至新机箱。然后，将受损机箱从设备机架或系统机柜中取出，并将同一型号的新机箱安装到位。

系统中的所有其他组件必须正常运行。如果未能正常运行，请联系技术支持。

* 您可以将此操作步骤与系统支持的所有 ONTAP 版本结合使用。
* 编写此操作步骤时，假设您要将所有驱动器和控制器模块移至新机箱，并且此机箱是 NetApp 的新组件。
* 此过程会造成中断。对于双控制器集群，此过程会导致完全服务中断；对于多节点集群，则会导致部分中断。
