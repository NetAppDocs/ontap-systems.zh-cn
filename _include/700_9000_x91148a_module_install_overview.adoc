您可以通过在已完全填充的系统中将 NIC 或存储适配器更换为新的 NIC 或存储适配器，或者将新的 NIC 或存储适配器添加到系统中的空机箱插槽中来向系统添加 I/O 模块。

.开始之前
* 检查 https://hwu.netapp.com["NetApp Hardware Universe"]以确保新的 I/O 模块与您的系统和正在运行的 ONTAP 版本兼容。
* 如果有多个插槽可用，请检查 https://hwu.netapp.com["NetApp Hardware Universe"]中的插槽优先级，并使用适合您的 I/O 模块的最佳插槽。
* 要无中断地添加 I/O 模块，您必须接管目标控制器，卸下目标插槽中的插槽空白盖或卸下现有 I/O 模块，添加新的或更换的 I/O 模块，然后交还目标控制器。
* 确保所有其他组件均正常运行。
