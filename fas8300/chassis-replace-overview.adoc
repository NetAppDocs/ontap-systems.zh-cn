= 在更换 FAS8300 或 FAS8700 系统中的机箱之前，请查看相关要求
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在更换 FAS8300 或 FAS8700 系统中的机箱之前，系统中的所有其他组件必须正常运行；否则，您必须联系技术支持。此过程支持所有 ONTAP 版本，但会导致双控制器集群中的完整服务中断以及多节点集群中的部分中断。

* 您可以将此操作步骤与系统支持的所有 ONTAP 版本结合使用。
* 此过程具有中断性：双控制器集群将经历完全服务中断，而多节点集群将经历部分中断。
