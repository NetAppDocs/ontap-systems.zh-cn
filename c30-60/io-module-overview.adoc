= 了解有关在 AFF C30 或 AFF C60 系统中添加和更换 I/O 模块的信息
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
AFF C30 和AFF C60 存储系统可灵活扩展或更换 I/O 模块，从而增强网络连接性和性能。在升级网络功能或处理故障模块时，添加、热插拔或更换 I/O 模块至关重要。

可以将存储系统中出现故障的 I/O 模块替换为相同类型的 I/O 模块或不同类型的 I/O 模块。当存储系统满足特定要求时，您可以热插拔集群和 HA I/O 模块。您还可以将 I/O 模块添加到具有可用插槽的存储系统中。

* link:io-module-add.html["添加I/O模块"]
+
添加额外的I/O模块可以提高冗余度、从而有助于确保即使一个I/O模块发生故障、存储系统仍可正常运行。

* link:io-module-hotswap.html["热插拔 I/O 模块"]
+
热插拔某些 I/O 模块以替换为等效模块，可以将存储系统恢复到最佳运行状态。热插拔无需执行手动接管。

+
要使用此过程，您的存储系统必须运行ONTAP 9.17.1 或更高版本，并且满足特定的系统要求。

* link:io-module-replace.html["更换I/O模块"]
+
更换发生故障的I/O模块可以将存储系统还原到其最佳运行状态。
