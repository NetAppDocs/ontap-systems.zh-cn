= 在自动启动恢复过程完成后，将故障的 AFF A800 启动介质退回给 NetApp
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
完成 AFF A800 系统中故障启动介质的自动启动恢复过程后，将故障部件返回 NetApp。有关详细信息，请参见 https://mysupport.netapp.com/site/info/rma["部件退回和更换"]页面。
