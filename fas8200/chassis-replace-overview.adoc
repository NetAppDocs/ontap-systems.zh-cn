= 在更换 FAS8200 系统中的机箱之前，请查看相关要求
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在更换 FAS8200 系统中的机箱之前，请验证所有其他组件是否正常运行，并且更换的机箱是来自 NetApp 的相同型号的新组件。该过程需要将电源、风扇和控制器模块移动到新机箱中，并且具有破坏性，会导致双控制器集群完全服务中断或多节点集群部分服务中断。

系统中的所有其他组件必须正常运行。如果未能正常运行，请联系技术支持。

* 您可以将此操作步骤与系统支持的所有 ONTAP 版本结合使用。
* 编写此操作步骤时，假设您要将控制器模块移至新机箱，并且此机箱是 NetApp 的新组件。
* 此过程会造成中断。对于双控制器集群，您将遭遇完全服务中断；对于多节点集群，则会出现部分中断。
