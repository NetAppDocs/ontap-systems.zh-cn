= AFF A400 机箱更换工作流程
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
通过关闭控制器、将硬件移至更换机箱并完成系统恢复，开始更换 AFF A400 系统机箱。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["一个"]link:chassis-replace-shutdown.html["关闭控制器"]
[role="quick-margin-para"]
关闭控制器以安全地进行机箱维护。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["两个"]link:chassis-replace-move-hardware.html["更换机箱"]
[role="quick-margin-para"]
将风扇、驱动器和控制器模块从受损机箱移动到更换机箱。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["三个"]link:chassis-replace-complete-system-restore-rma.html["完成机箱更换"]
[role="quick-margin-para"]
通过验证 HA 状态来完成更换，如果需要，请切换回聚合，然后将故障机箱返回 NetApp。
