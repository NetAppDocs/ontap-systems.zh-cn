= 更换 FAS2600 机箱之前查看要求
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在更换 FAS2600 系统中的机箱之前，请查看将电源、硬盘驱动器和控制器模块从受损机箱移动到新机箱的要求，以及将设备机架或系统机柜中的受损机箱更换为同一型号的新机箱的要求。

系统中的所有其他组件必须正常运行。如果未能正常运行，请联系技术支持。

* 您可以将此操作步骤与系统支持的所有 ONTAP 版本结合使用。
* 编写此操作步骤时，假设您要将所有驱动器和控制器模块移至新机箱，并且此机箱是 NetApp 的新组件。
* 此程序具有破坏性。对于双节点集群，服务完全中断；对于多节点集群，服务部分中断。
