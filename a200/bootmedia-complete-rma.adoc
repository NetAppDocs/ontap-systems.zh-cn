= 将故障的 AFF A200 启动介质退回至 NetApp
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
更换启动介质后，按照套件随附的 RMA 说明中的描述，将故障的 AFF A200 启动介质退回给 NetApp。有关更多信息，请参阅 https://mysupport.netapp.com/site/info/rma["部件退回和更换"]页面。
